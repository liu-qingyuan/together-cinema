# Changelog

## 0.2.0 — room scenery and screening journal

- Full-screen scenery opening, personal day/night appearance, and a retracting hover-only navigation underline.
- Room-scoped screening journal with bounded history; local visual preferences do not change synchronized playback.
- Eight credited room scenes; the release check accepts only the exact reviewed opening clip.
- Clean up room membership even when the initial welcome cannot be delivered.
- Known limitation: Android Quark half-frame rendering is not verified fixed.

## Initial source distribution

- Standalone Compose build; one-command installer and explicit data-preserving uninstall.
- Local-only default; optional protected HTTPS and optional dynamic extractor.
- Self-contained original SVG backgrounds and retained vendor notices.
- Existing watch-party, library, subtitle, keyboard, chat and optional TURN voice behavior carried forward.
- Android Quark overlay report remains unresolved; no production deployment changed by this export.

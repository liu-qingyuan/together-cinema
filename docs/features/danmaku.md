# 影片弹幕的持久化

## 当前行为

弹幕按房间与影片保存为纯文本，并按影片时间和序号读取；重开放映室后仍能读取。删除影片时清除该影片的弹幕。

## 限制与剩余

每条最多 120 个字符，每个房间的单片上限 5000 条。此记录只覆盖弹幕存储和关联的交互测试，不证明浏览器绘制、播放性能或其他模块已通过验收。

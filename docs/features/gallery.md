# 展厅与放映室入口

## 当前行为

普通 `/` 展示随部署提供的默认封面、陪伴文案、房间码入口和下滑可达的片库区域。保留会话时可只读浏览私人片单；无授权会话时只显示权限提示。浏览展厅不登录、不建立房间连接、不加载影片。

`/?room=AB` 邀请自动沿用原房间码登录校验，成功后直达对应放映室；无效邀请停在入口并提示，可修改房间码重试，不回退到记住的房间。进入放映室后展厅装饰动画与滚动动画停止，即使影片暂停也不恢复。退出返回普通入口并清除授权会话。

播放器、聊天、弹幕、语音及房间同步沿用原实现。`scripts/gallery_smoke.py` 在本地 Compose 实例上通过两个独立浏览器进程验证入口、授权隔离和生成短片的同步播放／暂停／跳转，并清理自有测试影片。

## 限制与剩余

默认封面复用已有原创矢量背景，尚未提供「动漫天空」「雪山银河」最终素材或全站共享封面上传。片库权限仍是受信任好友共享模型；房间码不是密码，也不是房间间的媒体隔离。片单在打开展厅时读取，不实时刷新。

浏览器测试需要可选的 Playwright、Chrome（或已安装的 Chromium）和 ffmpeg；不纳入无浏览器依赖的 unittest 默认命令。390×844 模拟与减少动态检查不构成手机实机或最终美术验收。

# 展厅与放映室入口

## 当前行为

片库上传每半秒更新有效速率与预计剩余时间，时钟只估算传输、不包含校验或转码。分片校验后的缓冲区用于发送及重试；瞬时网络故障按分片退避重试，权限、空间等错误直接报告。刷新页面或重启服务仍不能续传。


仓库的展厅入口／视觉脚本 `scripts/gallery_smoke.py`、`scripts/gallery_visual_smoke.py` 显式设置 `zh-CN` 测试语言，避免宿主 Chrome 默认英文使中文定位器失效；安装布局脚本同样固定中文。双语界面与指南取流仍由已有 `scripts/locale_smoke.py`、`scripts/guide_smoke.py` 验证。仓库默认 README 使用英文，首屏可切换简体中文；两版分别提供部署、邀请、视频解析与同步路径，指南中的安装链接返回同语种 README。仓库首页语言不改变放映室的语言偏好或应用协议。

放映室在 1360 CSS 像素及以下使用两行顶部：房号与在线状态在首行，复制邀请与具名「房间操作／Room actions」入口在次行。切换房间和退出共用原按钮与 handler，移入菜单；退出以分隔线和警示色区分，移动主要按钮至少 44 × 44 CSS 像素。菜单支持触摸、Enter／Space、Tab／Shift+Tab、Escape、外部点击及焦点离开收起；取消或关闭房间对话框后焦点返回入口。回到桌面断点时恢复既有平铺操作与主导航，不更改房间权限、邀请格式或同步协议。横屏给首屏标题额外留白。`scripts/mobile_header_smoke.py` 用临时应用、合成房间与真实中英文，检查 320／390 竖屏、844 横屏和 1440 桌面布局、剪贴板邀请、实际切房与退出；前后对照及限制见 `docs/mobile-header-acceptance.md`。

公开观众指南位于 `/help/zh-CN.html` 和 `/help/en.html`，无需入房或会话、无脚本，两页可互链并独立分享，指南语言不写放映室偏好。展厅入房卡与放映室片库的帮助入口按本机界面语言指向对应页面，在新标签页打开，不重载播放器或连接。帮助页随镜像交付，按白名单公开读取且不缓存 HTML；中英文 README 的页首直达 GitHub Pages 双语项目站和对应语言的观众指南。项目站以放映室天空图作全屏封面，窄屏使用竖裁图；下滑的快捷入口可直达入房、选片及直连／中转对比。主介绍页用系统无衬线字体、白色和银灰底展示真实截图；截图随页面语言，窄屏顺序排版。仅宽屏且未要求减少动态时让导航段滚过封面，不接管滚轮。详细帮助复用随站指南，不提供公共放映室。

指南包含建房、邀请、房主控制、片库、自有双视频网页中明确选第二段的流程；区分直连的各自原站媒体请求与中转的本站媒体请求，说明 HLS 入口清单、流量、默认全站额度与并发、临时片源、可选动态解析、无候选／过期／额度不足的下一步。不绕过访问控制，不索取第三方凭据；注明 VideoTogether 的交互思想参考而非其兼容范围。网络表单使用通用网页／HTTPS 媒体文案，解析和候选保持原协议；可选解析服务连接失败也返回已有稳定错误标识与本机语言的操作提示，不再落入通用 500。

`scripts/guide_smoke.py` 用两独立 Chrome 上下文、临时生成的红／蓝两短片和非 YouTube 自有网页，验证明确选择第二段、两端片名与暂停／续播、直连和中转请求路径、成员不能访问原站但服务器可取流时中转继续，以及打开／切换帮助不触发媒体重载、重连或控片。只将 `media.example` 的传输映射至本地 HTTP fixture，保留真实解析／中转／房间流程和公开地址校验；不代表公开 DNS／TLS 或外部站点验收。禁用动态解析、空候选保留当前影片；额度／过期以真实 HTTP 错误探针验证，未声称中途耗尽验收。证据和安装／升级说明见 `docs/guide-acceptance.md`。

观影设置提供简体中文／English 界面语言，只保存在本浏览器的 `watchLanguage`，不进入房间快照或 WebSocket 播放协议。显式选择优先；未选时按浏览器语言列表匹配中文或英文，无匹配回退简中。存储受限仍可当页切换。独立语言 Module 集中拥有字典、日期格式、文本及无障碍名称绑定；就地更新导航、设置、侧栏、连接／错误状态、个人风景标签和播放器可控菜单，不重建视频或字幕轨、不调用控片。聊天和放映手记按本机语言重绘日期，底层时间戳不变；原片名、昵称、聊天、弹幕、字幕轨名称／内容和作品署名保持原文。

HTTP 错误保留原 status／纯文本正文并增加 `X-Cinema-Error`；WebSocket 错误保留 `error` 并增加 `code`，转换失败返回附加 `error_code`。新界面优先按稳定标识呈现双语提示，未知标识或旧版无标识响应仍显示原始可读信息，不匹配中文句子。网络状态词条集中在同一字典。默认 Python 回归检查字典两种语言、插值名称及引用键；CI 另跑 Node 的偏好／错误兼容测试。`python -m scripts.locale_smoke` 用临时生成短片和原文 VTT、两个独立浏览器上下文验证语言隔离、播放继续、零重载／重连／语言触发的同步消息、用户内容不变以及刷新、语言匹配与禁用存储，证据见 `docs/evidence/locale.json`。

「外观模式」只在放映室的「观影设置」面板中调整；悬浮导航仅保留跳转入口，展厅沿用本机选择。默认按观看设备本地时间自动切换：07:00 起为日间，19:00 起为夜间；页面开着也会切换。手动日间或夜间保存在本浏览器，优先于时段；选回自动即恢复。外观不写入房间、不改变影片亮度或个人风景。

普通 `/` 展示当前全站共享封面（初始为随部署提供的「动漫天空」）、陪伴文案、房间码入口和下滑可达的片库区域。可在本页预览「雪山银河」，不保存个人主题或修改全站状态。天空在云间排字；银河桌面图旁排字，手机宽度下在入房表单后保留完整 2:3 竖幅照片，不横裁或遮挡主体。保留会话时可只读浏览私人片单；无授权会话时只显示权限提示。浏览展厅不登录、不建立房间连接、不加载影片。

`/?room=AB` 邀请自动沿用原房间码登录校验，成功后直达对应放映室；无效邀请停在入口并提示，可修改房间码重试，不回退到记住的房间。进入放映室后展厅装饰动画与滚动动画停止，即使影片暂停也不恢复。退出返回普通入口并清除授权会话。

封面图片为 Unicorn Creates 和 oliwok 的 CC BY 4.0 作品，署名、来源及裁切／压缩说明随 `web/assets/scenes/sources.json` 和许可文件部署，不重标 MIT。只请求当前预设对应的桌面或手机派生图，邀请不下载展厅封面，入房移除封面图片来源。玻璃仅增强入房卡和预览按钮，基础样式不透明；减少透明度或无滤镜增强时保留可用表单，文字、影片、字幕和诗句不叠玻璃。

放映室仅提供个人选景，不再展示全站封面管理面板。兼容原有共享封面数据和 API；写入同时验证授权 cookie 与当前活动房间连接私发的成员凭据；仅有历史登录会话仍为只读。访客可公开读取目录和当前派生图，刷新即见共享选择。源图和两种优化 WebP 保存在 `/data/covers`，沿用 `RESERVE_BYTES` 预留，失败保留原封面并清理源图／派生图；内置预设不可删除，删除非当前图不切换，删除当前图回退天空并释放整组文件。

封面不绑定影片或房间，不更改个人主题，不广播播放命令。自定义图旁排字，手机宽度在入房表单后完整显示；放映室不加载展厅图片。`scripts/covers_smoke.py` 在本地隔离 Compose 上以两独立 Chrome 进程和另一无会话访客验证上传、选用、失败与删除；播放生成的带字幕测试片时检查零媒体重载、字幕保留、进度同步和实际 WebRTC 音频传输继续。使用模拟测试麦克风，不代表异地 TURN／真机通话验收，证据见 `docs/cover-acceptance.md`。

播放器、聊天、弹幕、语音及房间同步沿用既有协议。当前本地影片被删除或网络片源被回收时，放映室统一清空选片、暂停、将进度归零且保持为零，退出临时加速并恢复已选基础倍速；迟到或重复的失效通知不停止后来选的影片。房主、成员和放映记录保留，其他房间观看不同影片不受影响；本地删除仍刷新共享片库。`tests/test_source_unavailable.py` 用临时本地文件和受控网络片源，经双成员 WebSocket 验证这些状态，不代表浏览器解码或外网片源验收。`scripts/gallery_smoke.py` 在本地 Compose 实例上通过两个独立浏览器进程验证入口、授权隔离和生成短片的同步播放／暂停／跳转，并清理自有测试影片。`scripts/gallery_visual_smoke.py` 验证两种构图的资源选择、焦点和片库滚动，以及减少动态／透明度和基础静态 CSS 下的真实入房；截图与明确未验收项见 `docs/gallery-visual-acceptance.md`。

放映室有独立的本机风景选集：八款有作者署名、原作链接的摄影或手绘壁纸，按设备请求单张大图；选择后同时更新放映室页首、背景和选景大图。通过缩略图列表选景。它不写全站封面，不驱动播放器；滚动视差与换景揭幕仅在风景可见或操作时响应，播放、全屏、隐藏页面、关闭动效或减少动态时停用。

进入房间先见铺满视口的个人风景，导航和房间按钮浮在画面上，只有后续内容限制阅读宽度。默认「盛夏晴空」在开场可见且允许动效时播放站内 6 秒无声短片（212,022 字节，由该场景原图制作）；其他风景保留自己的图片。减少动态、关闭风景动效或启用受支持的省流量偏好时不请求开场短片，加载或播放失败时保留风景。允许动效时，滚动进度控制镜头和标题，放映区从下方覆盖短暂停留的风景；不拦截滚轮或触摸。离开开场、播放影片或全屏时停止装饰播放和滚动动画。也可点击「向下进入放映」直达播放器与侧栏。页面后段保留观影设置及其原有直达链接，首次打开或刷新后三项全部收起。

日间模式的内容区使用柔白底；夜间模式的私人风景列表、已选图、竖图衬底及风景动效开关随界面变暗，不对风景照片套滤镜。摄影封面与黑色视频底不随界面提亮。聊天、成员和片库共用一枚滑动选中胶囊，支持点击、标签栏横扫和键盘方向键；减少动态时直接切换，语音在侧栏内独立分组，「发送」与「加入语音」固定黑底白字，不随风景换色；诗句、选景、观影设置和收尾延续同一组圆角与留白。

「陪伴」按当前房间展示共享放映手记。房主开始播放才登记片名和时间，暂停、续播或拖动进度不重复登记；全员离开后再次开场可记为新的一场。按最近时间排序，每房最多 60 场，全站最多 4096 场。影片下架不抹去片名，不留视频副本。旧版本未登记的场次不从片库或上传时间推算。

房间链接的 `#together` 可直达手记。无记录时列出十部明确标为示例的电影（日期也是样例），只在浏览器展示；有放映记录后整组换成真实片单。滚动整页时手记停驻一屏，居中的片名转黑，非当前片名为浅灰，翻过的再淡一档，桌面左栏仅展示标题、诗句和说明；右栏片单自成一条放映带，黑白齿孔仅夹住片单，不环绕整页。双栏时放映带起点给居中导航的展开宽度留白。窄屏竖向依次展示简介和放映带。白色齿孔随页面滚动少量正反走片，停滚即定格，帧号沿刻度随片单进度移动。片名随滚筒弧面转动：接近上下边缘时逐渐侧转，转过侧面后才隐藏；反向滚动沿原路返回。日期沿右侧 120° 扇形圆弧排列（中心上下各 60°），与对应片名保持同一高度，以小字显示本地播放日期，下滑或上滑可前后翻阅；到末尾自然离开，也可直接跳过。减少动态效果时逐条切换，不做帧间插值或字面旋转，齿孔保持静止。

页首为随视图切换的栏目导航。英文窄屏风景选集随可用宽度改为单列，长片名和分类可换行。展开的导航栏按可见品牌与栏目文字的实际宽度排列；收起时当前栏目保持单行，英文长标签不裁切。导航默认收起，不因滚动或返回页首自动展开；视口宽度足够（640 CSS 像素起）且使用鼠标时，胶囊从中心横向舒展，移开后原路收拢；以两端实际宽度过渡，不拉伸文字。触屏点击仍展开列表，与两侧房间操作的断点独立。栏目选中及悬停均为圆角，仅鼠标悬停约 100 毫秒后，黑色短线才用 600 毫秒从左向右展开，移出时在原项用 320 毫秒向左收回，不回到当前栏目；键盘焦点可见，减少动态时直接切换。支持背景模糊时，导航与触屏菜单用半透明毛玻璃透出背景；减少透明度时回退白底。夜间的中央导航使用乳白半透明玻璃，房间号、在线状态与操作按钮悬停时转为白底深字。日间两侧控件采用浅色毛玻璃，仅可操作按钮在鼠标悬停或键盘聚焦时原地渐变为石墨黑底白字。减少动态时直接变色，减少透明度时使用实底。导航的主题彩边有一束慢速环绕的高光；开启减少动态效果后保留静态彩边，强制颜色模式使用系统边框。触屏可点开菜单，键盘可用 Enter／Escape 开合。影片播放且画面可见、或全屏时导航让出画面，不发送同步命令。

## 限制与剩余

语言只维护简中和英文，不提供站点级设置或翻译用户内容。浏览器／系统自有的文件选择、权限弹窗和原生校验提示仍由浏览器语言决定；旧服务器或未知错误的原始详情不保证译文。语言浏览器验收使用本机 Chrome 和合成媒体，不代表外网 provider、生产部署或手机实机验证。手机顶部使用 Chrome 视口与触摸模拟验证，不代表 iOS／Android 真机验收。

展厅顶部两预设按钮仍只影响当前页预览；刷新恢复全站选择。共享封面写入仅限当前活动房间连接，不是管理员或个人封面账户。封面切换不向已打开的访客页面推送；需要刷新。自定义图不保留动画，不提供裁切编辑器或原图公开下载。两种正式素材与响应式构图已提供，但真机美术与实际不支持滤镜的引擎验收仍待人工补齐；本机历史配对 iPhone 当前不可用，因此 #4 保持 open。片库权限仍是受信任好友共享模型；房间码不是密码，也不是房间间的媒体隔离。片单在打开展厅时读取，不实时刷新。

浏览器测试需要可选的 Playwright、Chrome（或已安装的 Chromium）和 ffmpeg；不纳入无浏览器依赖的 unittest 默认命令。390×844／320×568 模拟、偏好模拟及移除可选增强规则的基础 CSS 检查，不构成手机实机或实际无滤镜引擎验收。

准备运行环境

这份教程按当前 main 分支编写，从源码本地构建镜像。准备 Git、Docker Engine 或 Docker Desktop，以及支持 up --wait 的 Compose v2。启动 Docker，确认命令指向你要使用的引擎：

docker context show
docker compose version
docker info

只看本地影片，可从 1 核、1 GiB 内存起步，推荐 2 GiB。磁盘除了镜像和影片，还要能同时放下转换前后的两个文件。默认预留的 2 GiB 是写入保护，不是已经占用的空间。安装器不会替你安装 Docker 或修改防火墙。

先在自己的电脑上跑起来

git clone https://github.com/liu-qingyuan/together-cinema.git
cd together-cinema
./install.sh

不想用 Git？下载当前 main 分支的 ZIP 源码，解压并进入目录，只执行最后一行。首次构建会下载依赖；较旧的发行版可能与本指南不同。

怎样算成功？在运行 Docker 的电脑打开 http://127.0.0.1:8080，应该能看到展厅。输入 2～8 位字母或数字建房，确认页面显示房间号。这是本机地址，不要把它发给朋友。

打不开时，先看 docker compose ps 和 docker compose logs --tail=100 watch。如果端口已被占用，运行 ./install.sh --port 8088，改用该端口访问。

用 HTTPS 邀请异地朋友

在能被公网访问的服务器上部署，把自己的域名解析到这台服务器，并允许入站 TCP 80、443。在服务器的项目目录运行下面的命令，把示例域名换成自己的：

./install.sh --domain cinema.example.com

使用 HTTPS 打开你的域名。站点登录用户名是 cinema，密码是私有 .env 里的 SITE_PASSWORD；WATCH_PASSWORD 是内部密钥，不是登录密码。如果证书还没签发，检查 DNS、端口和 docker compose logs --tail=100 https。

只邀请信任的人。房间码不是访问密码，也不隔离片库。获准进入的人可以观看、上传和删除全站影片。不要把未保护的 8080 暴露到公网，不要分享 .env；邀请和网关口令请私下发送。

让另一位观众打开邀请，房主在一台设备暂停再播放，两边都应跟随。查看双人同步检查 →

按需开启视频解析和语音

网络视频

片库、公开 HTTPS 媒体直链和能从静态网页发现的片源都不需要浏览器镜像。要解析动态网页，请留出额外的构建空间，主机推荐至少 2 GiB 内存。在原项目目录运行：

./install.sh --network

首次公网安装也可以合用 --network --domain cinema.example.com。并非所有网页都能解析。选片前可看直连与中转的区别：中转会为每位观众消耗服务器出口流量。

房间语音

公网语音需要 HTTPS 和外部 TURN 服务。在私有 .env 中填写与该服务匹配的 WATCH_TURN_URLS、WATCH_TURN_SECRET，重新运行安装器即可应用配置。只用文字聊天不需要 TURN。

更新时保留片库

先备份私有 .env 和项目数据卷，等大家看完再更新：重建会中断连接。如果最初用 Git 安装，在原目录查看变更后运行：

git pull --ff-only
./install.sh
docker compose ps

如果最初用 ZIP 安装，在原目录更新源码，不要执行 git pull。保留 .env、Compose 项目名和原有命名卷。重跑安装器后，打开一部已有影片，确认字幕也在。

./uninstall.sh 只停止项目并保留数据。追加 --purge-data --yes 会永久删除项目卷，包括影片和证书；日常升级不要使用。
